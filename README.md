# srig.tech

Sriganesh Srinivasan's portfolio: projects, experience and résumé. Live at [srig.tech](https://srig.tech).

Built with Astro, Tailwind CSS and daisyUI, with project write-ups in MDX. Videos are served from Cloudflare R2, and the site is hosted on Vercel.

```bash
npm install
npm run dev     # local site
npm run build   # type-check and build to dist/
```
